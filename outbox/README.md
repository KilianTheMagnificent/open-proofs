# outbox

Drafts for the owner to review and, if they choose, send: misformalization reports for
formal-conjectures, write-ups of results, notes for erdosproblems.com threads.

One consolidated draft ([`issue-value-answers-ignore-parameter.md`](issue-value-answers-ignore-parameter.md))
was filed upstream as [`google-deepmind/formal-conjectures#7590`](https://github.com/google-deepmind/formal-conjectures/issues/7590);
all other drafts in this directory remain unfiled local notes. Agents must never submit, open issues
or PRs, comment, post or email on the owner's behalf; they only write drafts here.

Naming: `misformalization-<upstream-decl>.md`, `writeup-<claim-id>.md`, `status-<topic>.md`.
Each draft should state the pinned upstream commit, the exact Lean statement, the informal
statement it should capture, the evidence (checker verdict and the Lean proof file), and a
suggested fix.
