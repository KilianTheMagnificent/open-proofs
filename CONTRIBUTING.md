# Contributing to open-proofs

Issues and soundness feedback are welcome. If you spot a bypass in the five-layer checker (`scripts/check.py`, `scripts/lint.py`, or `OpenProofsChecker/Main.lean`), a questionable entry in `ledger/LEDGER.md`, or a broken reproduction step, please open an issue with your `lean --version`, the command you ran, and the smallest failing example.

Outside pull requests are closed because Andre directs development with AI coding agents and cannot personally review outside PRs.

For a suspected security issue or checker bypass you prefer to report privately, see [SECURITY.md](SECURITY.md).
